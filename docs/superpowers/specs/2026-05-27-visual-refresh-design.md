# 全站统一视觉升级设计规格

## 目标

将 ComprehensiveTools 从偏黑白灰、硬边框、页面风格割裂的视觉状态，升级为明亮、清爽、实用且有彩色模块感的静态工具站。改造应提升首页和主要工具页的观感，同时保持现有功能、数据结构、页面入口和脚本行为不变。

## 范围

本次升级覆盖全站共享视觉系统和主要工具页面：

- 首页 `index.html`
- 全局样式 `css/base.css`
- 计算器类页面：个税、房贷、理财、养老金、FIRE 退休规划
- 管理/清单类页面：库存、出行清单、点餐
- 康复训练页面

不在本次范围内：

- 重写业务 JavaScript
- 改动 localStorage 键或导入导出数据格式
- 引入构建工具、框架或包管理
- 大规模重排页面结构

## 设计方向

采用“清爽实用，有彩色模块”的工具台风格。

- 背景：从纯灰或深灰改为浅暖白、浅青、浅蓝的柔和底色。
- 卡片：白底或轻微半透明底，搭配浅色边框和柔和阴影。
- 主色：使用清爽蓝绿作为全站基础操作色。
- 辅助色：使用青、绿、橙、紫红等低饱和强调色区分工具类型和状态。
- 字体：沿用现有 `Outfit` 和 `DM Sans` 体系，中文保持系统字体回退。
- 圆角：保持工具感，卡片圆角不超过现有中等尺度，避免过度圆润。
- 动效：只保留轻量 hover、focus、进入动效，遵守 `prefers-reduced-motion`。

## 架构

以 `css/base.css` 作为统一设计系统入口，补齐可复用变量和基础类：

- 页面背景、文本、边框、阴影、圆角、状态色变量
- 通用返回按钮样式
- 通用卡片、按钮、表单、标签、结果区的视觉基线
- 焦点态和移动端触摸尺寸

页面自己的 CSS 或内联样式只做必要适配：

- 将纯黑、纯灰、硬边框变量映射到新的明亮色彩系统。
- 保留已有 DOM 结构和类名，减少脚本影响。
- 对明显简陋页面补充头部色块、彩色标签、结果区域层次。

## 页面策略

### 首页

首页作为工具入口面板，应最明显地体现升级：

- 背景改为浅色层次背景。
- 工具卡片增加彩色图标块、轻微顶部色带或浅色强调层。
- 卡片 hover 使用轻微上浮和柔和阴影。
- 每个工具可以通过 CSS 变量或 `nth-child` 获得不同强调色。

### 计算器页面

个税、房贷、理财、养老金、FIRE 退休规划使用一致的计算器视觉语言：

- 彩色头部或标题区传达页面主题。
- 表单输入区使用白色卡片，输入框焦点有清晰彩色轮廓。
- 结果区用浅色强调底，而不是纯灰表格感。
- 主操作按钮使用实色，次操作按钮使用浅色或描边。

### 清单和管理页面

库存、出行清单、点餐保留信息密度和原有工作流：

- 工具栏和筛选控件增加浅色背景与清晰边界。
- 标签、分类、完成状态使用彩色模块。
- 列表项从纯灰分隔改为白底卡片或轻边框行。

### 康复训练页面

康复训练保留健康和运动感，但避免黑底荧光过强：

- 主界面转为明亮健康风格。
- 训练执行界面可保留高对比计时表现，但降低霓虹感，改用舒适绿色和深青色。
- 固定底部操作区保持清晰可点击。

## 可访问性与响应式

- 所有交互控件保留清晰 `focus-visible`。
- 移动端按钮和输入框保持至少 44px 可触控高度。
- 文本不能因新样式在按钮、卡片、工具栏中溢出。
- 避免只依靠颜色表达状态，必要时保留文字和图标。
- 遵守现有移动端布局断点，不新增复杂布局系统。

## 验证

实施后需要完成：

- 运行 `node --test`。
- 使用静态服务器打开 `http://localhost:8000/index.html`。
- 手动检查首页、个税、养老金、库存、康复训练、出行清单、FIRE 退休规划页面。
- 检查移动端宽度下标题、按钮、表单、卡片不重叠不溢出。
- 检查浏览器控制台没有新增错误。
